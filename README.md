## 注册前先搞清楚这两件事

第一件是邮箱。搬瓦工整个账号体系围绕邮箱运转：登录用邮箱，订单通知、续费提醒、机房更换通知都发到这个邮箱，KiwiVM 面板相关的邮件也是。所以别用一个不常登录的邮箱注册，否则以后 VPS 被暂停、流量快用完这类通知你看不到，出问题时会很被动。

第二件是账号数量。搬瓦工没有公开宣传"一人一号"，但社区里多年形成的惯例就是一个人只注册一个账号。原因很实际：客服会人工审核订单，同一身份证件、同一支付方式反复出现在多个新账号上，容易被判定为关联账号；第三方反馈里，被判定滥用规则的账号会被直接停用且不退款。另外，搬瓦工用户协议明确禁止账号买卖，网上收"二手号"再被原号主找回的纠纷并不少见，这条路不要走。

还有一个好消息：早年注册时让人头疼的验证码图片问题，现在基本已经不存在了，目前注册页面一般不会再出现需要人肉识别的验证码。

### 第四步：选择付款方式

搬瓦工目前支持四种付款方式：支付宝（Alipay）、银联（UnionPay）、PayPal 和信用卡。对国内用户来说差别主要在手续费和到账体验：

- **支付宝**：跳转后扫码支付，按汇率自动换算，全程中文页面，无额外手续费，第一推荐
- **银联**：同样走人民币结算，适合习惯用银行卡的用户
- **PayPal / 信用卡**：可用，但可能涉及货币转换费，美元扣款时汇率由发卡行决定

四者的付款成功率都正常，只是对国内用户来说支付宝最省心。

### 第五步：完成支付，等待开通

点 Complete Order 提交订单，然后点 Pay now 跳转到支付宝页面扫码付款。付款成功后页面会提示你回到 Client Area（客户中心），一般 3 到 5 分钟内 VPS 就会自动开通。

开通后到 **Services → My Services** 里能看到你买的 VPS，点击对应的 **KiwiVM Control Panel** 进入控制面板。搬瓦工的管理功能都在这个自研面板里：重装系统、开关机、快照、机房迁移、查看 IP，后续所有操作都在这里完成，不需要再回到购物流程。

**退款政策**：搬瓦工提供 30 天退款保证，付款后试用不合适可以申请退款，这一点在同类 VPS 服务商里算是给新用户留了退路。

**机房可以免费迁移**：KVM 和 CN2 GIA-E 系列支持在多个机房间自助迁移，CN2 GIA-E 迁入 CN2 优质线路机房时流量按 1/3 计。买了套餐觉得延迟不理想，先试试迁移而不是换套餐。

**续费价格不变**：搬瓦工套餐续费按购买价执行，不会首年便宜次年翻倍，配合循环优惠码，年付方案的长期成本很好算。

## 常见问题

**注册时需要科学上网吗？** 不需要。目前国内网络直连官网即可完成注册和支付，早年"验证码看不到"的问题已经基本消失，个别地区网络波动时换个浏览器或网络环境重试即可。

**填错资料了怎么办？** 登录后可以在账号设置里修改姓名、联系方式等信息。地址类信息不太精确没有关系，但姓名拼音建议保持真实，因为客服审核订单时会对着这些信息看。

**可以注册两个账号吗？** 官方没有明文限制注册数量，但关联账号、多账号套用优惠、账号交易这类行为一旦被判定违规，处理方式是封号且不退款。一个账号对绝大多数人完全够用，没必要冒险。

**为什么同一个套餐价格跟朋友买的不一样？** 大概率是对方用了循环优惠码，或者买的是不同计费周期。搬瓦工同套餐按月、季、半年、年付的单价不同，年付折算下来最便宜。下单前在结算页验证一次 BWHCGLUKKB，价格对齐了再付款。

**买 KVM 20G 还是 CN2 GIA-E 20G？** 只挂博客、跑脚本、对国内访问速度没要求，$49.99/年的 KVM 就够。如果主要给国内用户访问，或者自己日常要连上去用，CN2 GIA-E 的 CN2 GIA 直连线路在晚高峰的稳定性明显更好，多出来的钱花在线路上，这是搬瓦工的核心卖点。

**付款后多久能用？** 正常 3 到 5 分钟自动开通，开通邮件会发到注册邮箱。超过半小时没开通，去客户中心提交工单询问，这种卡单情况很少见但确实会发生。

注册这一套流程，难点从来不在表单，而在两个决策：选哪个套餐、用哪个优惠码。想清楚自己要线路还是要配置，付款前花十秒钟验证一次优惠码，剩下的步骤闭着眼睛都能走完。
